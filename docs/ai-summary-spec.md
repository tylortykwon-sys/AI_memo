# AI 메모 요약 기능 기획서

## 1. 개요

메모 상세보기 모달(`MemoViewer`)에서 메모를 AI로 요약하고, 요약을 메모에 저장해 두고 다시 볼 수 있게 한다.

- **AI 모델:** `gemini-3.1-flash-lite` (환경변수 `GEMINI_MODEL`로 교체 가능)
- **인터뷰로 확정한 방향:** 요약을 일회성으로 보고 닫는 것이 아니라, 저장해 두고 재사용한다.

## 2. 요구사항

### 2.1 목표

- 긴 메모를 열었을 때 핵심을 빠르게 파악한다.
- 요약은 메모에 저장되어 새로고침이나 모달 재오픈 후에도 유지된다.

### 2.2 포함 범위

| 항목          | 결정                                                                              |
| ------------- | --------------------------------------------------------------------------------- |
| 진입점        | 상세보기 모달 안의 "AI 요약" 섹션                                                 |
| 생성          | "요약하기" 버튼                                                                   |
| 갱신          | "다시 요약" 버튼으로 사용자가 직접 갱신                                           |
| 요약 형태     | 1~3문장의 짧은 한국어 요약                                                        |
| 길이 제한     | 메모 길이와 상관없이 항상 요약 가능 (단, 본문 20,000자 초과 시 요약 불가)         |
| 저장          | 메모(`Memo`)에 `summary`, `summarizedAt` 필드로 LocalStorage에 저장               |
| 표시 위치     | 상세보기에서만 표시                                                               |
| 로딩          | 요약 중 버튼에 "요약 중..." 표시, 버튼 비활성화(연속 클릭 방지)                   |
| 실패          | 모달 안에 한국어 오류 메시지 표시, 기존 요약은 유지, 같은 버튼으로 재시도         |

### 2.3 제외 범위

- 목록 카드는 변경하지 않는다. 요약을 표시하지 않고 본문 미리보기를 유지한다.
- 검색 대상에 요약을 포함하지 않는다.
- 본문을 수정해도 저장된 요약을 자동으로 지우거나 갱신하지 않는다. "오래된 요약" 표시도 하지 않는다.

### 2.4 제약

- **API 키:** 서버 쪽(Next.js API Route)에서만 사용하고 `.env.local`에 보관한다. 브라우저에는 노출하지 않는다.
- **프로젝트 규칙 준수:** `'use client'` 명시, TypeScript strict, 외부 상태 관리 라이브러리 금지, Tailwind 우선, 한국어 UI.
- **하위 호환:** `Memo`의 새 필드는 선택값으로 두어 기존에 저장된 메모와 호환한다.

### 2.5 추가 권장 사항 (인터뷰 이후 반영)

- 요청 15초 타임아웃
- 본문 20,000자 제한
- 요약 중 연속 클릭 방지
- 모델명을 `GEMINI_MODEL` 환경변수로 교체 가능하게 함
- 프롬프트에 "메모에 없는 내용을 추가하거나 바꾸지 말 것"을 명시

## 3. 설계

### 3.1 데이터 모델

```ts
interface Memo {
  // ...기존 필드
  summary?: string // AI 요약
  summarizedAt?: string // 요약 생성 시각 (ISO 8601)
}
```

### 3.2 API

`POST /api/summarize` (`src/app/api/summarize/route.ts`)

- 요청: `{ title: string, content: string }`
- 성공: `200 { summary: string }`
- 실패: `{ error: string }` (한국어 메시지)

| 상황                     | 상태 코드 |
| ------------------------ | --------- |
| 잘못된 요청 / 빈 본문    | 400       |
| 본문이 너무 긺           | 413       |
| 호출 한도 초과           | 429       |
| 키 미설정                | 500       |
| Gemini 호출 실패/빈 응답 | 502       |
| 타임아웃                 | 504       |

Gemini는 REST(`generateContent`)로 호출하며 키는 `x-goog-api-key` 헤더로 전달한다.

### 3.3 구성 요소

| 파일                                | 역할                                                                 |
| ----------------------------------- | -------------------------------------------------------------------- |
| `src/types/memo.ts`                 | `summary`, `summarizedAt` 필드 추가                                  |
| `src/app/api/summarize/route.ts`    | Gemini 호출 (서버 전용)                                              |
| `src/hooks/useSummarize.ts`         | 요약 요청, 로딩/오류 상태, 중복 호출 방지                            |
| `src/hooks/useMemos.ts`             | `setMemoSummary(id, summary)` 추가 (`updatedAt`은 변경하지 않음)     |
| `src/app/page.tsx`                  | 상세보기를 메모 id 기준으로 조회해 요약 저장이 모달에 즉시 반영됨    |
| `src/components/MemoViewer.tsx`     | AI 요약 섹션, 버튼, 로딩/오류 표시                                   |

### 3.4 환경변수 (`.env.local`)

```
GEMINI_API_KEY=발급받은_키
GEMINI_MODEL=gemini-3.1-flash-lite
```

## 4. 완료 판단 기준

- [x] 메모를 열고 "요약하기"를 누르면 요약이 표시된다.
- [x] 새로고침하거나 모달을 다시 열어도 요약이 남아 있다. (mock E2E로 검증)
- [x] "다시 요약"을 누르면 요약이 갱신된다. (mock E2E로 검증)
- [x] 호출이 실패하면 오류 메시지가 나오고 기존 요약은 유지된다. (mock E2E로 검증, 키 미설정 오류는 실제 화면에서 확인)
- [x] 실제 Gemini 호출로 요약이 생성된다. (첫 요약을 브라우저에서 확인)
- [ ] 브라우저의 네트워크 요청과 번들에서 API 키가 보이지 않는다. (키는 서버 라우트에서만 사용하도록 구현했으나, 번들 검사는 별도로 하지 않음)

## 5. 테스트

- E2E: `tests/e2e/summary.spec.ts` (Gemini 호출은 `page.route`로 mock)
  - 요약하기 → 표시 → 새로고침 후 유지 → 다시 요약
  - 실패 시 오류 메시지 표시, 기존 요약 유지
- 실행: `npx playwright test tests/e2e/summary.spec.ts --project=chromium`
- 확인 범위: chromium만 실행했다. Firefox, WebKit과 전체 `npm run test`는 실행하지 않았다.

## 6. 열린 질문 / 후속 과제

- 모델 ID `gemini-3.1-flash-lite`는 Google 공식 문서가 아닌 서드파티 글에서만 확인했다. 호출이 404/502로 실패하면 모델명을 먼저 확인한다.
- 본문 수정 후 요약이 오래되었음을 알리는 표시는 제외했다. 필요하면 `summarizedAt`과 `updatedAt`을 비교해 추가할 수 있다.
- 루트 `AGENTS.md`에는 Next.js 15.4.4로 적혀 있으나 실제 설치 버전은 16.2.9다. 문서 정정이 필요하다.
- Windows 셸의 curl로 한글을 보내면 인코딩이 깨져 요약이 엉뚱하게 나온다. API를 수동 테스트할 때는 UTF-8을 보장하는 방법(Node 등)을 쓴다.
